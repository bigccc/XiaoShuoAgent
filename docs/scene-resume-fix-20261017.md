## 已确认原因

- 当前运行的 /Applications 应用与上一轮发布副本相同。
- 点击继续后，任务重新进入修订，随即因“本章场景依据已改变，请编辑保存或重新规划后继续”暂停；调用次数没有增加。界面却显示通用“已暂停，点击继续”，把实际原因折叠进技术详情。
- 本轮AI生成时自动捕获场景卡，随后AI修订正文但没有返回可选场景卡。正文版本前进、自动卡片来源仍为旧版，下一次修订把这份可选旧资料当作必须通过的前置条件，形成反复暂停。

## 修复

1. 过期的 writing-origin 自动场景卡不再阻止生成；它们不进入模型依据，不被自动确认或刷新。始终读取最新正文/资料；如果模型返回新卡片，沿用已有捕获与历史机制。
2. 作者手动保存或明确规划的场景卡仍要求复核。生成前后及提交事务里仍比较原始计划id/revision，不能因忽略旧自动卡片而覆盖生成期间的新计划。
3. 续跑先检查问题证据版本；引用目标范围外的章节/资料变化也会让相关目标章重新检查。只因证据变化不把任务新稿伪装成作者旧稿；实际作者改稿仍保留原有待审保护。
4. 暂停主区域直接显示原因和“查看第N章场景卡”入口。只读读取场景状态：自动卡片可“重新检查并继续”，作者计划必须核对保存后才启用继续；读取失败给出重试。提交时按钮显示“正在继续…”，旧证据明确标“原文已更新，等待复查”。
