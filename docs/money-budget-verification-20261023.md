# 有限自动修正与金额预算验证

日期：2026-10-23。源码验证后已完成 v0.3.1 打包、公开发布及本机应用替换。

## 行为

- 新章一次逐窗检查；明确事实冲突最多一次局部修正及验证。字数、文风、节奏仅提示，默认不进行整批跨章复核。
- 补齐章节跳过已有正文；重启、金额补充不重置修正次数。检查缓存忽略价格、配置名称与无关版本变化，复用时重新核验当前证据。
- 所有 AI 入口采用人民币单价与操作预算；空价格禁止调用，明确零价格可用。费用按请求当时价格快照记录，未知用量保留预留。
- 请求发送前使用 UTF-8 字节与消息开销保守预留。重试新旧任务共享账本，独立后台调用没有金额授权时等待手动处理。
- 账本首次创建前备份本机 SQLite；历史与导入任务没有账本时显示费用未知。

## 已通过

- `npm run check`：类型检查；49 个测试文件、748 项单元及集成测试；148 项明暗主题对比度检查；生产构建。
- `npx playwright test tests/e2e/billing.spec.ts`：3 项 Electron 桌面用例通过。
- 桌面验证：缺价不能开始；取消确认零模型请求；零元预算在网络请求前暂停，明确提高至 10 元后从同一任务恢复，仅生成一次、检查一次。
- 受控模型报告用量下，累计估算 0.0012 元、剩余预算 9.9988 元与账本一致。
- 覆盖缓存价格、不同配置共享服务地址、失败重试、未知用量、微元精度、并发预留、崩溃恢复、预算补充、任务别名及长篇预估。

## 尚未验收

真实模型费用验收需要先在模型配置中填写实际服务单价，再批准小额操作预算。本轮未使用用户的付费连接，未将受控模型结果视为服务商账单验收。

安装包制作、替换已安装应用及发布已完成，详见 [v0.3.1 发布验证](releases/v0.3.1-verification.md)。两架构安装副本各通过 12 项桌面专项；原有完整桌面测试集未整体重跑。
