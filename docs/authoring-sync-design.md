# 阶段成果与辅助工具双向同步

作者明确授权实施，2026-10-09；2026-10-11 完成实现。概要、设定、大纲一起打通；双方可编辑，阶段保留全文自由编辑。

## 数据关系

概要绑定title、genre、background；设定绑定style、pace和character/world/location记录；大纲绑定storyline/outline/chapterOutline记录。其他内容以所属阶段supplement记录完整保留。targetWords/chapterWords不从叙述推断；正文摘要、实际时间线、知情和伏笔进展不由前期同步制造。

阶段包含有稳定blockId的绑定块，引用作品字段或noteId。已同步全文由这些记录渲染；自由编辑先保存草稿，5秒停笔后归类。辅助字段编辑直接重投影，不调用模型。草稿和辅助记录冲突时保留双方，阻止推进，提供选择。生成阶段优先返回结构化blocks；只有旧格式content时执行必需整理，不靠可选notes字段。

## 统一提交

每次同步保存SyncJob及SyncBatch；验证作品与所有依据修订后，一次事务写字段、记录、绑定、阶段文本、同步状态与历史。同名不模糊合并，改名用原noteId。唯一同类型同标题同正文可复用旧记录；身份歧义或正文差异进入首次关联差异确认。明确移除绑定后仅归档syncManaged且无其他绑定的记录，独立记录保持完整。

整段整理使用当前作品模型，最多一次结构修复，网络重试沿用provider规则。按源行范围归类以保证没有未覆盖的非空行；无法分类行进入supplement。归类后的正文由源文提取，不依靠改写来猜测事实。新版本取消过时任务。错误/取消/关闭保留草稿，重启不自动无限重试；显式继续或重试触发整理。

继续、生成与检查读取同步屏障后的版本。历史恢复同时恢复批次关联内容，出现后续独立修改时先处理冲突。备份v3包含绑定、任务、批次、归档历史并重映射ID；兼容旧包v1/v2。数据库v3升级前一致备份，不剪裁长文本。

## 验证与交付

先失败回归：三个阶段映射、双向编辑/改名、不丢补充、重复无新增、移除归档/独立记录、修订冲突、过时/取消/关闭、格式修复上限、同步屏障、历史恢复、旧数据及备份。完整服务与Electron回归，隔离真实模型验证可用配置，arm64临时安装验收。保留旧产物，不替换/Applications。

## 实现补充

- 手工记录首次关联有差异时保留双方。差异展示后的新修改再次触发版本冲突；阶段草稿变化则旧提案失效，重新整理最新全文。
- 同轮多阶段更新先比较实际引用身份，显式 ID 与唯一精确复用均参与校验；不同内容拒绝整批提交。共享补充的 supplementStage 是主要资料分类，不限制其他阶段引用。
- 历史提案与快照保留当时分类，不按后来改变的当前分类拒绝作品包。导入副本改名建立零模型调用的投影批次，原历史不改写。
- 旧格式 content 必须完整行范围整理；旧模型仅返回已分类的字段／规划 notes 时，程序确定性整理成同一份块，保留明确 noteId，其他阶段内容作为补充说明。前期阶段生成不应用动态事实笔记。
- rawResponse 保留模型原始文本；无效引用不能进入可应用的结构化历史。可选顶层 null 按未提供处理，必要字段与引用继续严格校验。
- 多阶段后段失败时，前段有效成果保留为未同步草稿，所有任务结束，避免丢失生成内容或遗留运行状态。
- 结构化成果引用不存在的 noteId 时，每个阶段最多请求一次关联修复（关闭网络层重试），仅接受原块序号到当前作品同分类资料 ID／新增标记的映射，不接受正文、标题或移除范围变更。修复后重新校验重复引用、已有绑定及差异；跨作品、已知分类错误和非法移除直接拦截。修复调用数与用量计入 SyncJob；失败保留阶段原文为未同步草稿，取消或期间编辑仍使旧结果失效。原始错误 ID 只留在 rawResponse，不写入可应用提案。
