# 创作流程简化验证（2026-10-24）

## 范围与结果

基于 `ed05669`，在独立分支 `codex/simpler-authoring` 实现。

- 全部 AI 操作取消费用预确认、金额预算与累计 Token 拦截；无价格仍可调用，缺价/缺用量显示未知。旧任务无需追加预算即可继续。
- 保留价格快照、请求用量、保守费用估算和后台同步的记账归属；单次输出长度、有限重试、手动暂停/取消、版本校验保留。
- 写前本地整理有来源的阅读提示，生成及检查使用同一套事实约束；不增加准备请求。
- 新稿事实冲突合并局部修正一次，验证修改片段与完整相关证据范围。修正后未解决的冲突不会被静默丢弃。
- 集中处理按钮明确授权一次实际修正；普通继续/检查不授权再次改稿。旧版本 `revisionRounds=1/2` 的新稿也能按作者决定执行。
- 无证据的疑点与检查器明确承认的知情推测保留为未证实提示；不用于自动改稿，也不声称这些疑点已被排除。
- 短章节生成给 JSON 和可选辅助资料留出输出空间，单次上限仍为 32,000 Token。已有正文被跳过时，不再误显示为“正文有更新”。
