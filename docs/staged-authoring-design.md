# 分阶段对话创作

2026-10-09，作者经第二轮 grill-me 确认。

默认流程为故事概要、必要设定、故事大纲、正文创作。概要包含核心冲突、人物成长、关键转折及结局方向；设定围绕情节组织人物关系、世界规则、背景与基调；大纲明确全书主线和近期 3—5 章。每阶段一次整体确认，作者可授权连续完成指定阶段。

「继续／按推荐」接受当前完整成果并进入下一阶段；修改请求留在相应阶段。明确要求提前试写允许执行，但保留规划进度。上游变动后自动整理下游影响，相关规划集中确认；已有正文仍遵守明确回改范围和版本保护。旧作品沿用已有进度，AI 根据现有正文和资料补齐必要规划。

左侧保持持续对话，右侧可编辑当前阶段成果。概要、设定、大纲、正文四个入口允许随时查看，查看本身不批准或改变阶段。手动修改与AI修改都保留成果历史；上游修改标记下游待更新。阶段状态、确认信息和成果随作品持久化及备份。
