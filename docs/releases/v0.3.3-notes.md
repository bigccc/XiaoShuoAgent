# 小说工坊 v0.3.3 预览版

2026-10-24。源码提交：`04ff3ec feat: simplify writing review and repair flow`。

## 本次改进

- 新稿继续采用一次局部修正和修改处验证，不因文风、节奏或篇幅建议反复改写。
- 已有正文检查后，以证据锚定的局部补丁生成修改预览；原稿在采纳前不变，采纳或放弃后按当前正文重新检查。
- 同一正文版本不再反复提供默认修订；可补充新处理意见或手动编辑，最多两轮候选。
- 明确事实冲突仍阻止完成；可兼容或推测性结论保留为未证实备注，不直接放行真实矛盾。
- 候选携带故事状态版本，生成后状态变化会阻止采纳，备份恢复时按当前身份重算有效指纹。
