# 小说工坊 v0.2.0 预览版

2026-10-16。包含六阶段优化，保持“定故事 → 做准备 → 开始写”的作者流程。

- 远章原文召回与出处，来源版本改变后重新读取。
- 故事状态与伏笔候选/采纳/复核，计划与事实分开。
- 场景计划和绑定原文的定向待审修订，段外正文保留。
- 作者认可样本、叙述文风与角色语言卡，可撤销和恢复历史。
- 完整检查窗口复用、依赖局部重查、疑点去重、预算预留与快速试写后认真定稿。
- 场景/主支线/人物提及/视角/伏笔五视图，分页导航、可忽略提醒及明确范围修订。

提供macOS 13.0及以上的Apple Silicon（arm64）和Intel（x64）DMG/ZIP。更新前请导出完整`.novel`作品包、退出应用，再覆盖安装。数据升级至v9，并在对应迁移前自动备份；旧包仍可导入，模型密钥不随作品包导出。

继续采用完整临时签名，尚无Developer ID签名/Apple公证，首次下载需按系统提示确认。Intel运行验证使用Apple Silicon上的Rosetta，不能替代原生Intel设备验收。真实模型文学质量、作者采纳率和账单改善没有新增评测。

下载包、SHA-256与安装副本测试明细见发布资产`SHA256SUMS.txt`、`verification.json`及[安装指南](https://github.com/bigccc/XiaoShuoAgent/blob/v0.2.0/docs/installation.md)。旧v0.1.0资产保留。
