# 小说工坊 v0.3.1 预览版

2026-10-23。减少自动改稿消耗，统一用人民币金额管理 AI 花费。

- 新章逐窗检查，明确事实冲突最多局部修正一次并验证；取消默认整批重复复核。字数、文风、节奏仅提示。
- 补齐及续写跳过已有完整正文；重启、恢复及增加金额不重置自动修正次数。
- AI 连接增加输入、输出及可选缓存单价。所有 AI 操作开始前展示预计花费与金额预算，记录累计估算、预留及剩余金额。
- 预算不足时在下一次请求前暂停，确认金额后恢复原任务；重试共享累计账本。没有金额授权的独立后台操作等待手动处理。

升级后请先在 AI 连接中填写实际价格（元／百万 Token）；免费模型明确填 0。旧配置及作品保留。没有历史价格的任务显示历史费用未知，不回算为零。金额按配置与报告用量估算，未知用量保守预留，实际账单以模型服务商为准。

更新前备份作品并退出应用，再覆盖安装。首次创建本机费用账本前自动备份 SQLite；作品数据版本仍为 v9。

提供 macOS 13 及以上 Apple Silicon（arm64）和 Intel（x64）DMG/ZIP。延续临时签名，尚无 Developer ID 签名或 Apple 公证；Intel 在 Apple Silicon 上通过 Rosetta 验证，未在原生 Intel 设备验收。未新增真实付费模型的账单或文学质量评测。

资产提供 SHA-256 与 verification.json。安装说明见[安装指南](https://github.com/bigccc/XiaoShuoAgent/blob/v0.3.1/docs/installation.md)。
