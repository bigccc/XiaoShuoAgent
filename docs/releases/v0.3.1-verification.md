## 构建与安装副本

- `npm run check`：49 个测试文件、748 项测试、类型检查、148 项主题对比度检查及构建通过。
- 两架构均重新制作安装包；DMG/ZIP 完整性、严格深度签名、版本号、架构及 ASAR 文件核对通过。
- 每架构从 DMG 复制独立安装副本，卸载镜像并临时禁用开发构建后，运行 12 项桌面用例：价格缺失拦截、取消确认零请求、预算暂停与原任务恢复、保存与重启、主题、快捷键及窗口访问隔离。
- arm64：12/12 通过（18.3 秒）；x64：12/12 通过（238.9 秒，Rosetta）。
- 首次 arm64 测试为 11 通过、1 失败：旧测试允许的 IPC 清单漏掉新增费用接口。更新清单，并增加两个接口对未授权窗口的拒绝断言后，完整复跑 12/12 通过。业务代码未因此修改。
- Framework 的 14 个相对链接均在应用内部有效；包内只包含运行文件、生产依赖、许可证及版本信息。
