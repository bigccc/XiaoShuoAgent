# 小说工坊 v0.3.2 预览版

2026-10-24。减少创作过程中的重复确认，取消应用内成本卡控。

- 所有 AI 操作直接执行：取消费用预确认、金额和累计 Token 预算拦截。旧预算暂停任务无需追加预算即可继续。
- 模型价格变为可选统计信息。缺少价格仍可运行，费用显示未知；保留用量、费用估算及手动暂停/取消。
- 写前自动整理已有事实及承接提醒；新稿的明确事实问题合并局部修正，随后只验证改动和完整关联证据。
- 需要作者决定时集中呈现，点击“按推荐处理并继续”执行一次实际修正。普通续跑不会再次授权改稿，作者已有正文继续受到保护。
- 无有效证据或明确属于推测的疑点只保留提示，避免进入无效检查整理循环。
- 为短章节正文和辅助 JSON 留足输出空间，保留单次输出限制与有限重试。

758 项测试、25 项桌面专项流程、类型检查、148 项明暗主题对比度检查和构建通过。3 组虚构故事实际模型样例最终自动完成；这是小样本分阶段回归，不代表普遍成功率或文学质量保证。详见[验证记录](https://github.com/bigccc/XiaoShuoAgent/blob/v0.3.2/docs/simpler-authoring-verification-20261024.md)。

提供 macOS 13 及以上 Apple Silicon（arm64）和 Intel（x64）DMG/ZIP。延续完整临时签名，尚无 Developer ID 签名或 Apple 公证。Intel 运行通过 Apple Silicon 的 Rosetta 验证，未在原生 Intel 设备验收。安装包验证详情见附件 verification.json。

更新前备份作品并退出应用，再覆盖安装。作品数据库仍为 v9。后台资料同步费用已经记账，阶段面板暂不单独展示费用汇总。

发布附件包含 SHA-256 校验文件。安装说明见[安装指南](https://github.com/bigccc/XiaoShuoAgent/blob/v0.3.2/docs/installation.md)。
