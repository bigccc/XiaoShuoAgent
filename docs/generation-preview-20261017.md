# 键盘操作、流式预览与对比度保障

2026-10-17。实施范围依据 `superpowers/plans/2026-10-17-stream-preview.md`。

## 作者可见行为

- ⌘S立即保存当前编辑器/表单；手动表单保存保留当前位置，原校验及冲突保护继续生效。普通提交与快捷键共用保存锁，保存中锁定手动表单，失败保留输入。
- ⌘1～5切换书架、创作、看稿、故事资料、设置；无作品时2～4不执行。切换经过原有未保存保护，弹窗/输入法组合输入/长按时忽略全局快捷键。
- 诊断和未保存窗口使用原生模态对话框，焦点限制在弹窗，ESC关闭后恢复焦点。未保存弹窗ESC返回编辑，保存过程中不能关闭或重复提交。
- 创作回复、阶段成果、试写与连续写作正文在完整响应返回前逐段显示。临时文本始终标为“生成中预览，尚未保存”；正式保存、待审稿及检查状态仍分别呈现。
- 预览只读，不能混入正文、版本历史、导出或后续上下文。修订预览不覆盖作者编辑器；取消/失败清除预览，保留原有诊断与恢复入口。检查和格式恢复只显示阶段，不显示内部控制数据。
- 预览在底部时自动跟随，向上阅读后暂停，并提供“回到最新”。读屏只播报阶段，预览正文关闭live播报。

## 实现约束

复用Provider SSE回调，新增主进程内存预览服务及固定IPC `novel:generation-delta` / `novel:generation-preview`。preload仅暴露 `onGenerationDelta(handler)`（返回取消订阅函数）和 `generationPreview(projectId, acknowledgedAttemptId?)`。沿用可信主窗口与主frame来源限制，不暴露IPC事件或凭据读取API。

增量JSON解析器只提取类型化路径白名单：message、artifacts的content/blocks.text、chapters.content及连续写作content。处理任意切片、转义、Unicode、字段乱序，拒绝重复键/伪装路径/无效结构；解析不支持时退回阶段提示，最终响应仍经过既有完整校验。artifact content优先于同一成果的blocks。

首个可显示分片立即推送，后续最多50ms批量发送；请求尝试与序号隔离重试、乱序和迟到事件。脱敏处理跨分片凭据。应用重载先订阅再读快照，缺失事件重新同步。完成预览保留到工作区最新快照应用后再确认移除；主进程最多保留32份未确认完成预览。应用退出不持久化临时预览，复用任务中断恢复机制。

快照刷新等待较新的刷新真正应用后才确认完成，避免一秒轮询与完成刷新交错造成短暂空白。本轮保留原有轮询周期，不进行全局轮询重构或数据库迁移。

## 检查与验收

`npm run check` 串联类型检查、Vitest、对比度审计和构建。对比度审计从tokens读取明暗主题，检查148组明确的文本、语义、选区、按钮、必要边界和焦点配对；普通文本4.5:1，必要控件和焦点3:1，装饰/禁用项单列。Electron测试补充实际CSS继承、透明合成、hover、focus与selection。只调整相关颜色，不进行整体视觉重构。

本轮回归包含：弹窗焦点/ESC、手动及自动保存、原生必填校验、慢保存去重/锁定、中文输入法、JSON任意切片/伪装路径、跨片脱敏、重试、取消、完成确认、重载，以及受控SSE在结束前500ms内可见且正式正文未提前写入。

最终单测/桌面回归、DMG安装副本和真实模型结果分别记录于 `generation-preview-package-20261017.json` 与 `generation-preview-live-20261017.json`。真实验收采用隔离作品及已配置供应商，最多20请求、累计300000 Token预算、20分钟，任一达到停止；未知用量保留预留，证据仅元数据。安装副本不替换日常 `/Applications` 应用。

没有重做长对话滚动、CSS拆分、骨架屏、字体/纸色、引导或i18n。非SSE响应一次显示完整结果，不模拟打字；旧格式的notes/project更新在正式完成后展示。

## 真实验收中的兼容性诊断

已保留多轮元数据记录（attempt1—attempt4）。验收代理的localhost路由会绕过Provider按官方主机名选择的请求选项，因此代理显式恢复当前JSON写作链路在官方服务上的非思考/JSON选项，继续逐块转发响应。跨次执行复用累计请求、保留预算和原始20分钟截止时间，不重置额度。

真实模型另有额外返回wordCount等输入/统计字段的情况，原校验仍严格拒绝，预览不冒充已保存正文。只强化生成指令，明确合法字段并禁止额外统计字段；未修改解析白名单或保存校验。新增回归确保含未知wordCount的回复仍失败且不落库。最终代码45个测试文件、673项单测通过。
