# 第五阶段：检查复用与成本控制

2026-10-14。沿用路线图与用户逐阶段继续授权；保持默认认真定稿、作者审阅、来源保护和持久用量。只实施源码/开发验收，不运行付费评测、发布或替换安装版。

## 完整检查结果复用

新增本地派生checkCache表，保留SQLite/作品包v8。缓存不属于作者数据，不随作品包导出或导入；旧应用可忽略新表，删除后重新检查。每作品最多256条，每条最多512KB，最旧条目淘汰，不进入poll。只有完整初检/独立复核（连续写作分别区分逐章检查和跨章复核）、结构/逐字依据验证成功且返回时来源有效的结果可缓存；失败、取消、预算中断、重大方向变更不缓存。缓存命中再次验证结构、原文及当前权限，不凭摘要直接宣布通过。

键包含项目、实际窗口全文与来源版本、检查用途/目标、完整规则及格式验证协议版本、作者要求、模型ID/配置/修订、输出规格、状态与表达摘要。仅复用完全相同的已检查窗口。连续任务的逐章/跨章进度与完成门槛也使用完整依赖指纹，要求或模型改变不能沿用旧覆盖。重新检查枚举全部窗口：未变化窗口复用，改变的依赖窗口重新初检并复核；同一章任何版本变化保守失效该章的所有窗口。没有证据支持的更细粒度跳过不实施。初检和跨章独立复核不互相复用。

复用次数/新检查窗口数保存在任务结果，展示检查覆盖及“复用已验证窗口”。命中不增加请求、费用预留或虚构节省Token；既有任务历史用量保持。用量未知仍保留完整调用预留，明确标为估算/预留，不以短回复替代未知账单。预算不足可保留前面已完成检查的缓存和进度，重启继续手动执行。

## 疑点去重

按类别、回改目标（连续任务）、经验证来源ID/版本与逐字证据集合识别相同疑点，忽略理由措辞和证据排列差异。跨窗口与重复任务不重复建同一问题；原文版本、引用内容或类别不同保留。作者已处理/忽略的问题保持处理状态；不做语义合并，不推断不同证据描述同一问题。

## 快速试写与认真定稿

默认认真定稿沿用规划、生成、逐章检查/有限修订和独立跨章复核。快速试写只允许一个尚未有正文的章节，完成规划和生成后保存草稿，进入等待作者状态，明确“尚未一致性检查”，不标检查完成或自动确认。作者点击“继续认真定稿”在同任务、同预算与累积用量上执行剩余检查；暂停、重启和导入不自动消费。作者可编辑试写稿，继续时以当前稿为源保留手改保护。

## 验证

真实SQLite/loopback HTTP测试相同输入零额外调用、原文/模型/规则/要求变更失效、改变局部只重查依赖窗口、失败及并发不入缓存、重启与包隔离、疑点去重及未知预留。固定冲突/正常状态迁移对照同时比较检出/误报和请求/用量；fixture只证明协议行为，真实模型漏检/误报和账单仍待单独评测。桌面覆盖复用说明、快速试写/手动认真定稿及恢复。
