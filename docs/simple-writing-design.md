# 简化写作与审核

2026-10-17，用户经 grill-me 访谈确认六项选择并要求「开始修改」。

默认流程：章数、每章约多少字、可选要求 → 开始写作 → 自动检查与修正 → 阅读成稿。

- 每章目标允许 ±10%；程序自己计数、补写或精简，不交给模型猜测字数。
- 普通界面不要求 Token。按目标规模、前文长度预估本次调用额度，保留有限修订与重试；异常保留进度，一键继续，不无限追加调用。
- 文风、节奏等主观建议不触发反复重写，不阻止任务完成；证据不足不能作为已证实冲突，也不能把未完成检查说成通过。
- 明确且影响后文、自动修不好的冲突暂停，展示原文与具体处理途径。重大剧情、人设、结局变更仍由作者决定。
- 本次生成的新稿自动修正；已有或作者编辑过的正文先展示差异，一键采用，旧版本可恢复。
- 场景、人物状态、伏笔自动整理，保留原文出处，自动参考不冒充作者确认。修改或删除来源后，不继续引用过期事实，不改作者确认设定。
- 默认入口与状态围绕写作结果，技术详情、记录与专业操作收起。兼容旧任务与保存数据。

验收分别记录：单元/服务回归、Electron 界面操作、构建、安装包、真实供应商。前几项不能代替后两项。
