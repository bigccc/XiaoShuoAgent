# 长篇阅读、审阅与 Agent 改稿

2026-10-11，作者完成三轮 grill-me 访谈并授权「OK 开始实现」。

阅读与审阅模式共用目录与段落位置。阅读连续滚动、邻章按需加载；保留上一章、下一章和章号跳转。支持字号、行距、阅读宽度，关闭重开恢复位置。目录支持分卷、章号／标题定位、全文搜索及未审／待处理筛选；未分卷作品不改变原顺序，手动按章范围建卷或采用 Agent 提议。

选段可批注或让 Agent 修改。批注先记录，作者选择一条或多条交给 Agent；Agent 修改后作者复核关闭。审阅状态独立于正文草稿／确认状态。已审正文修改后变为待复核，保留审阅基准以比较段落差异。选区改稿须严格保留区外正文，来源变动时拒绝覆盖。

局部与单章改稿直接保存并保留历史。多章先生成待审稿，展示段落差异，以章为采纳单位，也可整批采纳；相关改动提示一起处理。全书联动检查正文与关联设定、大纲、摘要、时间线；关键剧情歧义停下提问，明确呈现检查过、尚未检查及发生冲突的范围，不把检索命中视作全文一致性证明。

长任务预先列明范围及 Token 预算，预算内逐批执行；可暂停／取消，重启后手动续跑，保留已有待审稿。采纳前重新验证来源，冲突不覆盖。关联资料在相关候选处理完后集中采纳，保留冲突与未更新状态。

规模验证采用 5,000 章、约 1,500 万字以及历史版本。UI 不反复传输全书正文、历史和模型原始响应，目录只渲染可见窗口，正文读取与搜索在主进程按需执行。老作品和作品包兼容；新增批注、审阅基准、分卷及改稿任务进入备份并重映射身份。现有未提交成果原样保留。
