## 固定质量基线

运行：`npm run --silent benchmark:recall`。机器可读结果：[基准JSON](research/2026-10-13-recall-benchmark.json)。

- 11个自有固定情境、6处标注依据：原近期上下文找到3处；加入召回后找到6处。
- 新增召回的未预期章节为0；漏掉的标注章节为0；专门标注的同章后段转交证据句漏选为0。
- 控制项包含无相关原文、未来章、草稿、待复核、其他作品、泛操作请求；另外服务测试覆盖改稿、删除/恢复和请求并发源改变。
- 5000章、15,000,011字符的词条扫描：本轮记录约21.8ms，找到第8章。仅为这台机器的核心扫描时间，不包含数据库快照、模型调用、界面、磁盘和全流程耗时。

此基准衡量原文召回与保护，不测小说生成质量、全书事实检出率或费用。词条召回采用有界候选窗口，可能漏掉候选上限之外的相关内容，不能代替语义检索或人工阅读。字符量不等于服务商Token。
