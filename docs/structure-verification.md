# 第六阶段验证：结构导航

2026-10-14（Asia/Shanghai）。用户授权继续[路线图](optimization-roadmap.md)第六阶段，[设计](structure-design.md)及[计划](superpowers/plans/2026-10-14-structure.md)记录范围。保留原创作主流程；只交付源码与开发验收，不运行真实付费模型、不安装或发布。

## 已实现

- “看稿 → 结构导航”提供场景、主支线、人物出场、视角、伏笔五个视图；每页40条，章序范围/文字/人物/主支线筛选与原文定位。场景与主支线为作者计划，人物按姓名及最多11个明确别名作字面提及定位，提及不等于实际在场。
- 作者手工建立最多50条主线/支线、标题120/说明1000字符，关联总计1000场景；关联保留章节/计划/卡片身份及版本。归档找回、跨页选择、已选关联移除、10版工作区历史恢复。恢复保留原关联版本，不补造来源许可；模型不改结构工作区。
- 缺少视角、来源改变、关联改变/移除及预期伏笔回收提醒，展示具体依据并允许忽略/恢复，每作品最多1000条忽略记录。忽略绑定当前来源版本/摘要，正文再改会重新出现。最新已采纳伏笔决定回收提醒；候选回收/改类型不会隐藏原采纳埋设，正常已确认回收/放弃不再触发逾期。
- 问题入口支持视角一致、主支线衔接、人物表达、伏笔回收、删冗余和补阻力。作者点击才调用；绑定场景只改选段，章级只改当前章，默认预算100000 Token，高级设置可调整。复用既有sceneSource/selection与RevisionRunner，进入待审稿、作者采纳前正文不变；陈旧版本/无绑定/异作品目标拒绝，AI任务互斥保持。
- 查询通过SQLite筛选分页及页内元信息校验，不读取全书snapshot，不在响应中传正文。完整场景/故事状态仍在修订前由原服务复核，导航“来源改变”提示不代替一致性检查。poll不携带结构工作区/历史全文，配置和历史按需读取。
- SQLite与作品/恢复包v9，v8升级前一致备份，v1—v8兼容。当前/历史的线程、场景、章节和提醒目标ID重映射；删除的历史目标保留为失效链接，跨作品/伪造关联原子拒绝。模型配置、密钥与派生检查缓存不随包导出。

## 5000章基准

运行`npm run --silent benchmark:structure`，见[JSON证据](research/2026-10-14-structure-benchmark.json)。真实SQLite及结构服务，5000章、约1400万正文字符、1000份两卡场景计划、999条关联。禁用Store.snapshot，所有查询仍完成；导航响应没有正文全文，最大页40条、响应约1.1万字符。

- 场景末页：2000卡中的40条；视角搜索：1000个匹配中的40条。
- 人物姓名/别名：准确返回第8章与第4999章的两处文字提及。
- 主线末页：999关联中的40条，缺少场景的远章范围返回零行。

这是本机查询、分页及范围协议测试，不代表端到端UI延迟、实际人物出场识别、语义分析或文学质量。耗时见原始JSON，不以单次耗时承诺性能。导航没有AI请求。

[检查复验](research/2026-10-14-structure-check-regression.json)维持冷/热结果及末章变化的12窗覆盖；[文风](research/2026-10-14-structure-voice-regression.json)和[场景](research/2026-10-14-structure-scene-regression.json)200/2500/3000字各条件仍4请求；[召回](research/2026-10-14-structure-recall-regression.json)仍6/6标注依据、0漏选/未预期章/证据漏选。真实模型质量与费用缺测不变。

## 独立审查及修复

一次只读审查固定`69d0e0f..3563593`，3项Important，无Critical/Minor；统一补失败回归后修复，未另发复审：

1. 伏笔来源变化指纹只记“已改变”布尔值，忽略版本4后版本5仍隐藏：纳入当前正文版本、哈希/章序和人物版本。再次修改原文的提醒回归失败→通过。
2. 被删除场景不在选择器中，无法取消旧关联：提供独立已选关联清单，包括页外/失效项，显式移除后保存，保留其他关联。桌面失败→通过。
3. structure.revise遗漏writesWithAI，绕过互斥：接入同一检查。写作、文风提取、场景规划、故事提取四种运行状态分别失败→通过，未发模型请求。

审查另有保存后再编辑闭包疑点，隔离Electron未复现并排除；真实文学质量、付费平台/发布及整体回归由本轮交付边界与主执行者验证承担。未更改无关旧代码/历史截图。
