# 面向网文作者的界面改造

2026-10-13，依据本次 grill-me 访谈确认。

目标：从一个想法开始写新书的作者，不必了解模型或计算机知识。自助连接使用服务预设与密钥，并兼容提前配置。沿用本机保存、历史、待审稿与恢复机制。

## 功能归属

- 书架：新建、继续、导入、归档。
- 创作：想法/灵感起步；定故事、做准备、开始写；聊天与当前成果；试写、连续写作。
- 看稿：阅读、章节编辑/历史、问题检查、待审稿。
- 故事资料：作品信息、人物/世界、规划、共享素材。
- 设置：AI 连接、备份/恢复、高级连接参数；无作品时也能管理共享素材和查看任务记录。
- 作品操作区：导出、待处理/进度。旧辅助任务的生成/提取/来源复核保留在相关页面的更多创作操作中。

## 交互与验收

方向确认后默认集中准备设定和大纲，复用现有委托、同步与集中确认机制；修改、空白或待同步成果不得自动跳过。试写不确认规划。旧书按已有进度继续。宽屏聊天+成果，窄屏聊天/稿件切换。

作者设置范围、章数和字数；专业预算和模型分工收进高级设置。新稿自动保存；已有正文的改稿保留差异、采纳/拒绝和恢复。保存/检查进度分开；原文证据、范围限制和未完成状态保留。调用上限不等于账户余额；到限保留成果，由作者决定有限地继续。

验收：无需专业参数走到第一章；所有旧功能可达；切换时保存保护仍工作；写作/改稿可暂停、继续和审阅；导出/备份有效；最小窗口操作可达。


## 实现决策与验证记录

- 基于当前已修改的 codex/macos-authoring 分支执行，未复制或清理其他工作。
- 保留底层四阶段协议，方向确认通过既有显式委托集中准备设定和大纲；首次开书流程减少一次确认。
- 由于最小窗口为1050×680，单栏切换阈值采用1100px；宽屏保留两栏。
- 快捷继续每次增加100000 Token，受原任务最大值约束，并需作者点击；没有自动增加预算或真实模型连接调用。
- 为集中结构化准备补修预检查：先用blocks源文本构造临时文档以验证reviewGroup；最终提交仍经原归一化、授权和来源版本检查。
- 独立审查的两项P2（预算暂停仅记录reply、待处理遗漏连续任务）已有失败回归与修复。
