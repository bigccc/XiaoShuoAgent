# 连续写作提示界面调整

2026-10-16。将创作页累计技术警告改为当前结果和必要行动，保留正文保存、恢复、检查、待审及预算行为。

## 最终呈现

- 正文保存数量、检查数量仍分开显示。当前状态明确说明可以继续、需要处理剧情问题、需要确认创作方向，或需要检查连接设置。
- 历史警告、重试记录、检查窗口统计、原始错误及远章来源统一放进默认折叠的“技术详情”，去除重复文字，不逐条展示黄色框。
- 已知辅助资料整理记录合并为一条中性提示，并提供状态/伏笔与章节/场景卡入口。旧任务只有历史字符串，不能确认当前是否已补齐，因此明确表述“曾有未更新或未采纳”，不假装资料完整或推断仍全部失败。
- 文风、篇幅等局部建议默认折叠；阻塞问题自动展开，显示章节、原因、原文依据和查看章节入口。
- 新增按需、只读的问题依据接口，补齐原先工作区轮询裁剪证据导致的空白。接口验证任务编号及窗口来源，仅返回任务版本与问题列表，不返回原始模型回复或模型凭据。
- 即使同时存在检查问题，也保留当前创作方向提问；连接/密钥失败提供设置入口；正文修改后，不把旧检查标为当前已通过。
