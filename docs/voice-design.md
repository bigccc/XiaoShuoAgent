# 第四阶段：作者文风与角色声音

2026-10-14。用户继续路线图第四阶段，沿用当前会话原生实施＋末尾一次独立审查。保留创作/看稿/故事资料主流程、作者采纳、版本与预算恢复。只交付源码和开发验收，不付费模型评测、不安装或发布。

## 认可样本与档案

voiceRecords独立保存narration/character档案，角色绑定本作品人物资料ID及修订。字段为rhythm、sentenceLength、dialogueRatio、descriptionDensity、vocabulary、avoid、addresses、catchphrases、emotion，每项最多400字符。每条1—6个作者选择的原文样本，每处最多4000、合计最多12000字符，保存逐字quote、偏移、整章hash、章序和修订，含独立样本ID及approved标记。新录入默认样本未认可；作者勾选认可与档案确认是两项明确动作。草稿可选样，但提取/确认前来源正文须已确认且无需复核。

AI派生或手工编辑先是candidate。作者确认后accepted快照可用于表达参考；待审编辑/拒绝不覆盖之前的已启用快照。作者可关闭使用、归档、找回和恢复历史（最多50版）；历史恢复回到候选，不恢复原确认权限。角色资料改动、归档/删除、原文修订/内容改变、撤销认可或关闭使用，使旧档案退出自动参考。来源唯一重定位后的复核回到候选；原文内容改变的样本须重新认可。

同种类/人物键选择最近采纳档案，再校验来源；最新已采纳档案失效不回退旧档案冒充当前选择。作者勾选的样本与模型偶发输出分开，生成不自动学习或认可。文风规则及角色表达均可编辑，准确性由作者核对。

## 显式提取与预算

voice.extract仅读取作者已认可且来源有效的选段，不读取整章或其他作品。voiceJobs保存目标档案版本、来源指纹、调用/预算和状态；默认100000、最大1000000 Token，单次4000输出、一次provider尝试。格式不符不更新原档案；调用前预留，未知用量保留预留值。暂停/取消/失败/重启保留原档案，重启及导入不自动调用，明确继续才绑定本机连接。作者改档案、样本、人物或正文后旧回复不能覆盖。

## 创作参考与来源保护

只注入已确认、启用且来源有效的表达规则：叙述文风最多1份，按作者要求/目标正文/场景人物匹配最多4份角色语言卡。规则作为「表达参考，非剧情依据、非原文」独立元信息，原样本quote不作为新的全文授权或事实来源。最多8000字符且不超过上下文窗口四分之一，完整档案优先，不默默裁断规则；未纳入的档案披露。原文证据documents继续只有原文。

连续生成/修订、对话和定向改稿使用该参考，无额外学习调用；旧任务格式保持兼容。来源摘要含匹配query、表达窗口limit及实际已提供档案的版本/内容/样本证明，模型返回与采纳时核对，包含「原本没有档案→作者启用新档案」变化。改稿候选保存自身摘要；候选不能因任务后来更换范围而取得新许可。旧v7请求没有voice摘要，不假造曾参考文风。

## 存储、界面与验收

SQLite及作品包升v8，v7迁移前备份，v1—v7补空voiceRecords/voiceJobs。当前/采纳/历史样本及人物/任务ID重映射；伪造当前quote、跨作品引用或未认可样本冒充已采纳档案原子拒绝。导入前有效的表达摘要重建，失效摘要保持失效；连接配置和密钥不导出。

故事资料增加「文风与声音」分页40条，按需读取历史；poll不传全部档案/历史。表单保护未保存修改；明确样本位置、认可勾选、候选/使用/陈旧状态、角色绑定、编辑/撤销/归档恢复。预算与技术信息折叠。

真实SQLite/HTTP/Electron测试来源、采纳快照、角色范围、上下文预算、并发写保护、任务恢复与包兼容。固定200/2500/3000字及两角色样本记录输入/输出、请求和fixture用量，盲评表列角色辨识、叙述稳定、实际修改/保留量，未开展的人类评分保留null。fixture不证明文学质量、角色辨识率或账单改善；这些实测保留待单独验收。
