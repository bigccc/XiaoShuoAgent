# 第四阶段验证：作者文风与角色声音

2026-10-14（Asia/Shanghai）。用户授权逐阶段继续，本轮实施[路线图](optimization-roadmap.md)第四阶段；[设计](voice-design.md)与[实施计划](superpowers/plans/2026-10-14-voice.md)记录范围。第五、六阶段待实施。

## 已实现能力

- 「故事资料 → 文风与声音」管理叙述文风及绑定本作品人物的角色语言卡。9个表达字段、每项400字符；1—6处逐字样本、每处4000/合计12000字符，保存章节版本、全文哈希、位置与原文。样本默认未认可，草稿可先选样，提取或确认前来源正文须已确认且无需复核。
- 手工或AI规则先为候选，明确确认后才采纳。待审字段编辑保留原采纳快照；撤销样本认可、关闭、归档或来源失效均停止当前选择，不自动回退旧档案。作者可明确重新选择有效的已采纳版本。历史最多50版；恢复保留原始证明，形成关闭使用、未认可的候选，正文改变后仍可恢复字段，再复核和重新认可。
- 显式提取只发送认可选段，默认总预算100000/最大1000000 Token，单次输出4000、一次provider尝试。调用前预留，未知用量继续占用预留；格式错误或来源并发变化不覆盖档案。失败、暂停、取消、重启与导入保留数据，手动继续才调用本机连接；生成不自动学习文风。
- 连续写作、对话及改稿纳入独立表达元信息，最多1份叙述/4份匹配角色、8000字符且不超过原窗口四分之一；完整档案纳入，窗口遗漏有提示。样本文字不充当剧情事实或额外正文覆盖许可。多章改稿按实际当前章/选段及场景视角匹配，每份候选保存实际使用的摘要，返回和采纳前核对来源与权限。
- 列表分页40、历史按需读取、认可与来源可展开；未保存字段/样本保护导航，保存后执行确认使用新版本。AI提取完成时刷新干净编辑器，保留未保存手改。窄屏支持表单与列表滚动，预算/技术信息折叠。
- SQLite/作品包v8，v7迁移前一致备份，v1—v7兼容。当前/采纳/历史的样本、人物及任务ID重映射；导入有效摘要重建，失效摘要保持失效；v8任务摘要与实际表达元信息须成对，缺失时原子拒绝，不补造曾参考的内容。模型配置和密钥不随作品包导出。

## 独立审查及修复

一次只读独立审查固定 `463944b..be1dde8`，提出4项Important，无Critical或Minor；统一补失败回归后修复：

1. 最新样本认可被撤销时错误回退旧文风：先按作者选择次序分组，再检查关闭/归档/认可/来源；只有作者明确选择旧版才切换。补充关闭与归档回归。
2. 多章改稿沿用全任务截断query，后章错误匹配前章人物：逐实际章节构建参考、保存该候选摘要并传播窗口警告。六章用例验证后章正确角色。
3. 正文改变后历史恢复错误要求旧样本等于当前版本：保留历史字段与原始证据，恢复成未认可、关闭的候选，再复核定位。
4. v8导入缺少voiceText时会补造参考证明：摘要/元信息成对验证，原子拒绝缺失，旧v7两项皆无仍兼容。

审查另有尚未确认的表单版本疑点；桌面失败用例复现了“保存后确认”仍发旧版本号，已修复并通过。初次完整桌面运行53通过、2项旧同步用例失败；两项单独复跑通过，导航辅助函数在离开旧页后仍读旧工具区。测试改为等待实际对话区域，生产同步逻辑未改。最终完整57项回归全部通过。
