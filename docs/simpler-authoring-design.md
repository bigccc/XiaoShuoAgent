# 创作流程简化（2026-10-24）

本规格来自 grill-me 访谈，用户已确认全部推荐，并要求本版本所有 AI 操作取消成本卡控。

## 已确认范围

- 本轮重点是章节任务到可用正文；同时降低初稿事实冲突和人工介入次数。
- 所有 AI 操作取消费用预确认、金额预算与累计 Token 拦截。旧任务可继续；缺价格不阻塞。保留请求用量及费用估算，未知费用明确标记。
- 保留单次输出长度、有限技术重试、手动暂停/取消、版本检查。
- 写前自动整理现有事实、人物状态、场景目标与承接关系；生成与检查共享依据，不默认增加 AI 调用。普通细节自主补全，明确方向冲突集中询问。
- 本次新稿有证据的事实错误合并局部修正一次；针对修改处验证。文风、节奏、篇幅及未经证实的疑点仅提示。
- 修改作者已有正文仍需审阅；人设、主线、结局等方向变更集中决策。未解决的阻塞冲突保留草稿并暂停后续章节。
- 已有正文只有在当前版本检查完成、作者明确作出修正决定后，才以证据锚定的局部补丁生成一次修改候选，不做全章自由改写，并限制净扩写；原稿在采纳前不变。采纳或放弃候选后都按当前正文与资料重新检查；放弃不等于问题解决。
- 作者作出决定后必须进入实际修正，不能只重复检查；每次决定最多执行一轮修正，检查未通过不会自行重试。同一版本已尝试候选但冲突仍在时，需要新的处理意见或手动编辑；两轮候选后转人工，不重复默认修订。
- 不自动确认正文，不把人工“已审”当作 AI 检查通过，也不提供忽略阻塞冲突后直接完成的捷径。
- 验收同时比较初稿事实冲突、人工介入、自动完成、调用数/耗时/费用；不预先声称实际模型成功率。

## 验证边界

自动化回归采用隔离数据与本地模拟模型；固定代表样例前后对比验证控制流程。实际模型质量提升需要单独真实创作对比，不能由模拟结果代替。
